# knot — 초기 화면 디자인 가이드

> **문서 목적**: 초기 화면(랜딩 → 온보딩 → 로그인)의 **시각 디자인 기준**을 정의한다.
> **작성자**: 서비스 기획 / 디자인
> **대상 독자**: 디자이너 · 퍼블리셔 · 개발자
> **관련 문서**: 서비스 기획 → [03_초기화면_서비스기획.md](03_초기화면_서비스기획.md)
> **버전**: v1 (초기화면 한정)

---

## 1. 무드 & 톤

- **밝고 친근하며 깨끗한 느낌.** 흰 배경 위에 옅은 블루 글로우로 청량함을 줍니다.
- 여행·연결·젊음의 에너지를 **블루(메인)** 와 **컬러풀한 로고**로 표현합니다.
- 정보 밀도는 낮게, 여백을 넉넉히 두어 한 화면에 메시지 하나에 집중합니다.

---

## 2. 컬러 시스템

| 용도 | 색상명 | HEX | 사용처 |
|---|---|---|---|
| 메인 | Primary Blue | `#4A7FFF` | 주요 버튼, 인디케이터 활성, 강조 |
| 메인(밝게) | Primary Light | `#7BA4FF` | 그라데이션, 보조 강조 |
| 메인(어둡게) | Primary Dark | `#2E5FCC` | 버튼 눌림 상태 |
| 포인트 | Yellow | `#FFCB45` | 카카오 로그인 버튼 |
| 제목 텍스트 | Black | `#1C1C1E` | 제목·핵심 문구 |
| 본문 텍스트 | Grey | `#8E8E93` | 설명·보조 문구 |
| 배경 | Background | `#F5F7FA` ~ White | 화면 배경(상단 옅은 블루 글로우) |
| 라인/보더 | Light Grey | `#E9ECEF` | 구글 버튼 테두리 등 |

> 배경은 **상단에 옅은 블루 글로우 → 하단 화이트**로 흐르는 부드러운 그라데이션을 기본으로 합니다.

---

## 3. 타이포그래피

| 구분 | 스타일 | 비고 |
|---|---|---|
| 폰트 | 고운돋움 (GowunDodum) | 앱 전역 폰트, 부드럽고 친근한 인상 |
| 제목 | 굵게(Bold), 2줄 구성 | 검정(`#1C1C1E`), 줄바꿈으로 리듬감 |
| 본문 | 보통(Regular), 2~3줄 | 회색(`#8E8E93`), 가운데 정렬 |
| 버튼 텍스트 | 중간 굵기(Medium) | 흰색(블루 버튼) / 검정(노랑 버튼) |

- 제목은 의도적으로 줄을 나눠 ("한국 대학생이랑 / 진짜 한국 맛보기") 가독성과 리듬을 줍니다.
- 본문은 한 문장이 너무 길지 않게 끊고, 가운데 정렬합니다.

---

## 4. 공통 레이아웃 규칙

- **세이프 에어리어** 준수: 상태바(시계·배터리)와 하단 홈 인디케이터 영역을 침범하지 않습니다.
- **좌우 여백**: 콘텐츠는 화면 가장자리에서 일정한 안쪽 여백(약 24px)을 둡니다.
- **메인 버튼**: 화면 하단에 가로 꽉 차게(풀 와이드), 높이 약 56px, 모서리 둥글게(약 16px).
- **한 화면 = 하나의 메시지**: 요소를 많이 넣지 않고 중앙 시각물 + 문구 + 버튼으로 단순하게.

## 5. 화면별 디자인 스펙

### [1] 랜딩 화면
```
┌─────────────────────────────┐
│                       [🇰🇷]  │ ← 우상단 언어 버튼
│                             │
│                             │
│          (knot 로고)         │ ← 중앙
│      Your Local Vibe...      │
│                             │
│    한국의 진짜를 경험하는 여행    │ ← 메인 문구(검정, 굵게)
│  한국 대학생 친구와 함께하는...   │ ← 보조 문구(회색)
│                             │
│                             │
│   ┌───────────────────┐     │
│   │      시작하기       │     │ ← 풀와이드 블루 버튼
│   └───────────────────┘     │
└─────────────────────────────┘
```
- 언어 버튼: 국기 아이콘을 둥근 흰색 칩 형태로, 우상단에 배치.
- 로고는 화면 세로 중앙보다 약간 위.

---

### [2~4] 온보딩 화면 (공통 틀)
```
┌─────────────────────────────┐
│ ‹ 돌아가기          건너뛰기  │ ← 상단 바
│                             │
│         ┌─────────┐         │
│         │  일러스트  │        │ ← 둥근 사각형(앱아이콘 형태)
│         └─────────┘         │
│                             │
│        한국 대학생이랑         │ ← 제목(검정, 굵게, 2줄)
│       진짜 한국 맛보기        │
│                             │
│   우리 서비스는 한국 대학생...   │ ← 설명(회색, 가운데, 2~3줄)
│                             │
│          ● ○ ○             │ ← 페이지 인디케이터
│                             │
│   ┌───────────────────┐     │
│   │      다음으로       │     │ ← 풀와이드 블루 버튼
│   └───────────────────┘     │
└─────────────────────────────┘
```

**페이지 인디케이터**
- 점 3개. 현재 페이지는 **길쭉한 알약 모양 + 블루**, 나머지는 작은 회색 원.

**일러스트 가이드**
| 페이지 | 일러스트 | 모티프 |
|---|---|---|
| ① | 학사모 쓴 대학생 캐릭터 | 친구가 안내하는 진짜 한국 |
| ② | 학생 + 외국인 친구 | 취향 맞는 매칭 |
| ③ | 채팅 화면이 켜진 휴대폰 | 채팅으로 약속 |
- 모두 **둥근 사각형(앱 아이콘 형태) 안에 일러스트**, 파스텔/블루 톤으로 통일.

**버튼 라벨**
- 온보딩 ①·② : `다음으로`
- 온보딩 ③ : `지금, 바로 시작해보세요!`

---

### [5] 로그인 화면
```
┌─────────────────────────────┐
│ ‹ 돌아가기                   │ ← 상단 바
│                             │
│          (knot 로고)         │ ← 중앙
│      Your Local Vibe...      │
│                             │
│       여행을 시작해볼까요?      │ ← 유도 문구
│                             │
│                             │
│   ┌───────────────────┐     │
│   │ 💬 카카오로 시작하기  │     │ ← 노란 버튼(검정 텍스트)
│   └───────────────────┘     │
│   ┌───────────────────┐     │
│   │ G  Google로 시작하기 │     │ ← 흰 버튼 + 회색 테두리
│   └───────────────────┘     │
└─────────────────────────────┘
```

**소셜 버튼 스펙**
| 버튼 | 배경 | 텍스트 | 아이콘 |
|---|---|---|---|
| 카카오 | 노랑 `#FFCB45` | 검정 | 카카오 말풍선 |
| 구글 | 흰색 + 회색 테두리(`#E9ECEF`) | 검정 | 구글 G |
- 두 버튼은 같은 크기(풀 와이드, 56px)로 위아래 정렬, 카카오를 위에 배치.
- 카카오/구글 버튼은 각 브랜드의 **공식 디자인 가이드(색·로고)** 를 준수.

## 6. 인터랙션 / 모션

| 동작 | 효과 |
|---|---|
| 온보딩 페이지 전환 | 좌우 슬라이드 애니메이션, 인디케이터 부드럽게 이동 |
| 버튼 탭 | 살짝 눌리는 피드백(눌림 색 = Primary Dark) |

| 좌우 스와이프 | 온보딩 페이지 넘기기 가능 |
