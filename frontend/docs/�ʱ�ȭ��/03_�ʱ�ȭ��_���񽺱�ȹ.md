# knot — 초기 화면 서비스 기획서

> **문서 목적**: 앱을 처음 켠 사용자가 보게 되는 첫 흐름(랜딩 → 온보딩 → 로그인)의 **기획 의도와 요구사항**을 정의한다.
> **작성자**: 서비스 기획
> **대상 독자**: 디자이너 · 개발자 · 의사결정자 (비개발자 포함)
> **관련 문서**: 디자인 가이드 → [04_초기화면_디자인가이드.md](04_초기화면_디자인가이드.md)
> **버전**: v1 (초기화면 한정)

---

## 1. 서비스 소개

**knot**은 한국을 방문한 외국인과 한국 대학생을 **친구처럼 연결해 함께 로컬 여행**을 즐기게 해주는 매칭 서비스입니다.

- 가이드북·관광지 위주의 뻔한 여행이 아니라, **현지 대학생만 아는 진짜 한국**을 경험하게 합니다.
- 외국인에게는 "현지인 친구", 대학생에게는 "새로운 친구 + 활동"이라는 가치를 줍니다.

> **슬로건**: Your Local Vibe, Our Connection.
> **핵심 메시지**: 한국의 진짜를 경험하는 여행

---

## 2. 초기 화면의 목표

처음 앱을 켠 사용자에게 다음 세 가지를 순서대로 달성합니다.

1. **이게 무슨 서비스인지** 3초 안에 직관적으로 알게 한다. (랜딩)
2. **왜 써야 하는지**를 3장의 카드로 빠르게 설득한다. (온보딩)
3. **최소한의 마찰로 로그인**까지 자연스럽게 연결한다. (로그인)

### 성공 기준 (기획 관점)
- 온보딩 이탈 없이 로그인까지 도달하는 비율을 높인다.
- "건너뛰기"를 눌러도 로그인으로 바로 연결되어 흐름이 끊기지 않는다.
- 언어가 다른 외국인 사용자도 첫 화면에서 본인 언어로 볼 수 있다.

---

## 3. 전체 화면 흐름

총 5개 화면으로 구성됩니다.

```
[1] 랜딩            → "시작하기"
        ↓
[2] 온보딩 ①        → "다음으로"   (건너뛰기 시 → [5] 로그인)
        ↓
[3] 온보딩 ②        → "다음으로"   (건너뛰기 시 → [5] 로그인)
        ↓
[4] 온보딩 ③        → "지금, 바로 시작해보세요!"
        ↓
[5] 로그인          → 카카오 / 구글로 시작
        ↓
   (이후: 역할 선택 · 프로필 작성 — 별도 기획)
```

**공통 규칙**
- 온보딩 3개 화면은 좌우로 넘겨볼 수 있고, 하단에 현재 위치를 알려주는 점(인디케이터)이 있습니다.
- 모든 온보딩 화면 상단에는 `돌아가기`(이전으로), `건너뛰기`(바로 로그인으로)가 있습니다.

## 4. 화면별 기획

### [1] 랜딩 화면
**목적**: 브랜드 첫인상 전달 + 언어 선택 + 시작 유도

| 요소 | 내용 | 비고 |
|---|---|---|
| 언어 선택 | 우측 상단의 국기 버튼 | 한국어/영어/일본어/중국어 전환 |
| 브랜드 로고 | knot 로고 + 슬로건 | 화면 중앙 |
| 메인 문구 | **한국의 진짜를 경험하는 여행** | |
| 보조 문구 | 한국 대학생 친구와 함께하는 로컬 여행 매칭 | |
| 버튼 | **시작하기** | 누르면 온보딩 시작 |

> 💡 외국인 사용자가 첫 화면에서 바로 자기 언어로 바꿀 수 있어야 하므로, 언어 버튼은 **랜딩 화면에 반드시 노출**합니다.

---

### [2~4] 온보딩 화면 (3장)
**목적**: 서비스의 핵심 가치 3가지를 카드처럼 한 장씩 설득

각 화면은 **그림 + 제목 + 설명 + 버튼**의 동일한 구조이며 내용만 다릅니다.

#### 온보딩 ① — "친구가 안내하는 진짜 한국"
- **제목**: 한국 대학생이랑 진짜 한국 맛보기
- **설명**: 우리 서비스는 한국 대학생이랑 방문한 외국인 친구들을 이어줘요. 가이드북엔 없는 숨은 맛집·골목까지!
- **버튼**: 다음으로
- **전달 가치**: 관광지가 아닌 "현지인만 아는 진짜"

#### 온보딩 ② — "취향이 맞는 단 한 명"
- **제목**: 취향 맞는 친구 한 명이면 충분해요
- **설명**: 관심사, 여행 스타일만 골라두면 나랑 잘 맞는 메이트를 추천해줘요. 서울·부산·제주 어디든 현지 대학생이랑 같이!
- **버튼**: 다음으로
- **전달 가치**: 취향 기반 매칭 + 전국 어디든 가능

#### 온보딩 ③ — "약속은 채팅으로 간단히"
- **제목**: 일정은 우리끼리 채팅으로 OK
- **설명**: 추천 코스 참고하거나 맘대로 짜도 되고, 채팅으로 약속만 잡으면 끝! 이제 진짜 로컬 여행 시작해볼까요?
- **버튼**: 지금, 바로 시작해보세요!  → 로그인으로 이동
- **전달 가치**: 부담 없는 소통, 바로 시작 가능

---

### [5] 로그인 화면
**목적**: 가장 쉬운 방법으로 가입/로그인 (소셜 로그인)

| 요소 | 내용 |
|---|---|
| 브랜드 로고 | knot 로고 + 슬로건 |
| 유도 문구 | **여행을 시작해볼까요?** |
| 버튼 1 | 카카오로 시작하기 |
| 버튼 2 | Google로 시작하기 |

> 💡 별도의 회원가입 절차 없이 소셜 계정으로 한 번에 시작합니다.
> 신규 사용자는 로그인 후 자연스럽게 "역할 선택 → 프로필 작성"으로 이어집니다(별도 기획).

## 6. 사용자 시나리오

**시나리오 A — 외국인 관광객 (영어 사용)**
1. 앱 실행 → 랜딩 화면. 우측 상단에서 언어를 영어로 변경.
2. "시작하기" → 온보딩 3장을 넘기며 서비스 이해.
3. ③에서 "시작" → 구글 로그인 → 역할(외국인 여행자) 선택으로 이어짐.

**시나리오 B — 한국 대학생 (재방문)**
1. 앱 실행 → 랜딩 → "시작하기" → 온보딩 상단 "건너뛰기".
2. 곧바로 로그인 화면 → 카카오 로그인 → 기존 회원이므로 메인 화면 진입.

---

## 7. 정책/결정 필요 사항 (기획)

- [ ] 온보딩을 **첫 1회만** 보여줄지, 매번 보여줄지 (재방문자 경험).
- [ ] 언어 선택을 랜딩에서만 할지, 모든 화면에서 가능하게 할지.
- [ ] 로그인 수단에 **Apple 로그인** 추가 여부(아이폰 사용자/외국인 비중 고려).
- [ ] 로그인 화면에 **약관·개인정보 동의** 문구를 어디에, 어떻게 노출할지.
- [ ] 온보딩 일러스트/카피의 다국어 버전 최종 검수 주체.
