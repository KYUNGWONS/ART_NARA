# knot — 초기 화면(온보딩 & 인증 진입) 기획서

> **문서 목적**: 신규 리빌드 버전의 첫 진입 흐름(랜딩 → 온보딩 3단계 → 로그인)을 정의한다.
> **대상 독자**: 프런트엔드(Flutter) 개발자
> **기준**: 기존 기술 스택 유지(Flutter / 다국어 KO·EN·JA·ZH / Kakao·Google OAuth)
> **버전**: v1 (초기화면 한정)

---

## 1. 개요

### 1.1 서비스 한 줄 정의
**knot** — 한국 대학생과 방한 외국인을 "여행 가이드 ↔ 관광객"으로 매칭해 주는 로컬 여행 매칭 서비스.

> 슬로건: **Your Local Vibe, Our Connection.**
> 국문 카피: **한국의 진짜를 경험하는 여행**

### 1.2 초기 화면의 역할
앱을 처음 켠 사용자에게 **(1) 서비스 가치를 3컷으로 빠르게 인지**시키고, **(2) 최소 마찰로 소셜 로그인까지 연결**하는 것이 목표다. 회원가입·역할 선택·프로필 설정은 본 문서 범위 밖(로그인 성공 이후 단계)이다.

### 1.3 화면 흐름 (전체 5스크린)

```
[1. 랜딩]
   │  "시작하기"
   ▼
[2. 온보딩 ①]  한국 대학생이랑 진짜 한국 맛보기
   │  "다음으로"  (← 돌아가기 / 건너뛰기 →)
   ▼
[3. 온보딩 ②]  취향 맞는 친구 한 명이면 충분해요
   │  "다음으로"  (← 돌아가기 / 건너뛰기 →)
   ▼
[4. 온보딩 ③]  일정은 우리끼리 채팅으로 OK
   │  "지금, 바로 시작해보세요!"
   ▼
[5. 로그인]   여행을 시작해볼까요?
   │  카카오 / Google 로그인
   ▼
(역할 선택 · 프로필 설정 — 본 문서 범위 밖)
```

- **건너뛰기**: 온보딩 ①~③ 어느 단계에서든 누르면 곧바로 **[5. 로그인]** 으로 이동한다.
- **돌아가기**: 이전 스크린으로 복귀(온보딩 ① 에서는 [1. 랜딩]으로).
- 온보딩은 **가로 스와이프(PageView)** 로도 페이지 전환이 가능하며, 하단 인디케이터가 현재 위치를 표시한다.

## 2. 공통 디자인 가이드

| 항목 | 값 |
|---|---|
| 기본 배경 | 화이트 계열 그라데이션 (상단 옅은 블루 글로우 → 하단 화이트) |
| 메인 컬러 | `AppColors.primary` (#4A7FFF, 밝은 블루) — CTA 버튼·인디케이터 활성 |
| 포인트 컬러 | `AppColors.yellow` (#FFCB45) — 카카오 버튼 |
| 텍스트 | 제목 `black`(#1C1C1E), 본문 보조 `grey`(#8E8E93) |
| 폰트 | `GoogleFonts.gowunDodum` (앱 전역 테마) |
| 세이프에어리어 | 상·하단 모두 적용 (상태바·홈 인디케이터 침범 금지) |
| CTA 버튼 | 풀-width, 높이 약 56px, 라운드 코너(약 16px), 단색 `primary` 배경 + 화이트 텍스트 |

> ⚠️ 색상·텍스트 스타일은 하드코딩하지 말고 `AppColors` / `AppTextStyles` 토큰을 재사용한다.

### 다국어(i18n)
- 모든 사용자 노출 문구는 리터럴 인라인 금지. `AppStrings`에 `static const Map<AppLanguage, String>` 으로 KO·EN·JA·ZH **4개 로케일을 모두 채워** 등록하고, 화면에서는 `context.watch<LocaleProvider>().tr(AppStrings.key)` 로 렌더링한다.
- 본 문서의 카피는 **KO 기준안**이며, 개발 시 나머지 3개 언어 번역을 함께 등록한다.

### [2~4] 온보딩 화면 — `OnboardingScreen`

3개 페이지를 가진 단일 `PageView`. 각 페이지 구조는 동일하고 **아이콘 · 제목 · 본문 · 인디케이터 · 하단 버튼 라벨**만 달라진다.

**공통 레이아웃 (위 → 아래)**
- **상단 바**: 좌측 `‹ 돌아가기`, 우측 `건너뛰기`
- **중앙 일러스트**: 라운드 스퀘어(앱 아이콘 형태)의 캐릭터/오브젝트 이미지
- **제목**: 2줄, 굵게(black)
- **본문**: 2~3줄, 보조 텍스트(grey), 중앙 정렬
- **페이지 인디케이터**: 점 3개, 현재 페이지는 길쭉한 알약 형태로 `primary` 강조
- **하단 CTA**: 풀-width primary 버튼

| 페이지 | 일러스트 에셋 | 제목(KO) | 본문(KO) | 인디케이터 | CTA 라벨 |
|---|---|---|---|---|---|
| **①** | `onboarding_student.png` (학사모 쓴 대학생) | 한국 대학생이랑<br>진짜 한국 맛보기 | 우리 서비스는 한국 대학생이랑<br>방문한 외국인 친구들을 이어줘요.<br>가이드북엔 없는 숨은 맛집·골목까지! | ● ○ ○ | 다음으로 |
| **②** | `onboarding_friends.png` (학생+외국인 친구) | 취향 맞는 친구<br>한 명이면 충분해요 | 관심사, 여행 스타일만 골라두면<br>나랑 잘 맞는 메이트를 추천해줘요.<br>서울·부산·제주 어디든 현지 대학생이랑 같이! | ○ ● ○ | 다음으로 |
| **③** | `onboarding_chat.png` (채팅 화면이 켜진 폰) | 일정은 우리끼리<br>채팅으로 OK | 추천 코스 참고하거나 맘대로 짜도 되고,<br>채팅으로 약속만 잡으면 끝!<br>이제 진짜 로컬 여행 시작해볼까요? | ○ ○ ● | 지금, 바로 시작해보세요! |

**상호작용 규칙**
- `다음으로` (①·②): 다음 온보딩 페이지로 애니메이션 전환.
- `지금, 바로 시작해보세요!` (③): **[5] 로그인** 으로 이동.
- `건너뛰기` (전 페이지): 즉시 **[5] 로그인** 으로 이동.
- `‹ 돌아가기`: 이전 페이지로(① 에서는 [1] 랜딩으로).
- 좌/우 스와이프로 페이지 이동 가능. 마지막 페이지에서 우측 스와이프는 동작 없음(또는 로그인 이동 — 개발 협의).

### [5] 로그인 화면 — `LoginScreen`

소셜 OAuth 진입점. 회원/비회원 분기 없이 **소셜 로그인 → 백엔드 JWT 교환**까지 처리한다.

**레이아웃 (위 → 아래)**
1. **상단 바**: 좌측 `‹ 돌아가기` (온보딩 ③ 으로 복귀)
2. **중앙 브랜드 영역**: `knot_logo.png` + 슬로건
3. **유도 카피**: **여행을 시작해볼까요?**
4. **하단 소셜 버튼 2종**:
   - `[ 💬 카카오로 시작하기 ]` — 카카오 옐로우(`AppColors.yellow` #FFCB45) 배경 + 다크 텍스트
   - `[ G  Google로 시작하기 ]` — 화이트 배경 + 1px 그레이 보더 + 구글 G 로고

| 버튼 | 라벨(KO) | provider 값 | 처리 |
|---|---|---|---|
| 카카오 | 카카오로 시작하기 | `"KAKAO"` | `KakaoAuthService` → accessToken 획득 |
| Google | Google로 시작하기 | `"GOOGLE"` | `GoogleAuthService` → idToken 획득 |

**로그인 처리 흐름**
1. 소셜 SDK로 OAuth 토큰 획득 (Kakao: `accessToken` / Google: `idToken`).
2. `POST /auth/login` 에 `{ provider, accessToken }` 바디로 교환 → 앱 자체 JWT 쌍(`accessToken`/`refreshToken`) 수신.
3. 성공 시 응답의 신규/기존 회원 여부에 따라:
   - **신규 회원** → 역할 선택(`RoleSelectionScreen`) → 프로필 설정(`ProfileSetupScreen`)
   - **기존 회원** → 메인(`MainScreen`)
4. 실패/취소 시 토스트 안내 후 로그인 화면 유지.

> 백엔드 미연동 구간에서는 기존 **오프라인 mock 폴백 패턴**(`try { … } catch { return _mockXForOffline(); }` + `TODO(서버 연동)`)을 따라 UI 흐름이 끊기지 않도록 한다.

## 7. 미해결/협의 필요 사항

- [ ] 랜딩에서 첫 진입 시 자동으로 온보딩을 보여줄지, 재방문 사용자는 온보딩을 건너뛰고 바로 로그인으로 보낼지(온보딩 1회성 노출 여부).
- [ ] 언어 선택 UI 형태: 우상단 토글 vs 바텀시트.
- [ ] 온보딩 마지막 페이지에서의 우측 스와이프 동작 정의.
- [ ] 로그인 화면 하단 약관/개인정보 동의 문구 노출 위치(법무 검토).
- [ ] Apple 로그인(iOS 심사 요건) 추가 여부.
