# 기술 스택 & 구조

> ART_NARA 스페이스 > 1. 프로젝트 개요 > 기술 스택 & 구조

## 구성 요소

| 구성 | 스택 | 비고 |
|---|---|---|
| 앱 | Flutter (Dart) | KO/EN/JA/ZH 4개국어, Android 우선 (패키지 `com.artnara.artnara`) |
| 백엔드 | Spring Boot 3 + JPA, JDK 17 | 패키지 `com.example.artnara`. **Java 21 API 금지** |
| DB | H2 파일 모드(dev) | `~/artnara-db/`, `ddl-auto: update`. MySQL 전환은 환경변수만으로 가능 |
| 관리자 콘솔 | 정적 웹 (HTML + ES 모듈) | 빌드 도구 없음. `python -m http.server` 로 구동 |
| 실시간 | STOMP WebSocket (`/ws`) | 채팅 + 경매 현황 브로드캐스트 공용 |
| 푸시 | FCM HTTP v1 | firebase-admin 없이 jjwt + java.net.http 로 자체 구현 |

## 앱 화면 구조

- 하단 내비 **6탭**: 홈 · 판매 · 지도 · 제작의뢰 · 알림 · 마이페이지 (채팅 탭 없음 — 작품 문의는 홈 헤더 햄버거 서랍)
- 헤더는 `메뉴(햄버거) · 화면 제목 · 알림 벨` 한 줄
- 진입 흐름: 스플래시(자동 로그인) → 로그인(카카오/네이버) → 역할 선택(작가/컬렉터) → 프로필 설정 → 메인
- 역할 매핑: 작가 = `KOREAN_STUDENT`, 컬렉터 = `FOREIGN_TOURIST` (가입 후 상호 전환 가능)

| 텍스트 | primary `#141413` · secondary `#6B665E` · 테두리 `#E0DBD1` |
| 타이포 | Noto Sans KR — Heading 28 Bold / Section 22 / Body 16 / Caption 12 |
| Spacing · Radius | 8·12·16·24 / 8·14·22·Full |
