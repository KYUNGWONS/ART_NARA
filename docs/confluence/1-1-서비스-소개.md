# 서비스 소개

> ART_NARA 스페이스 > 1. 프로젝트 개요 > 서비스 소개

## 한 줄 정의

**ART NARA(아트나라)** — 미대생의 미술품을 사고파는 거래 플랫폼. 기능 명세의 원천은 사업계획서 PDF(『DUST-ART 미대생 미술품 거래 플랫폼 사업계획서 2026』, 레포 루트에 보관)이다.

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 3탭 거래 | 구매 / 판매 / 제작 의뢰. 판매는 즉시 판매와 **경매** 두 방식 |
| 경매 · 역경매 | 작품 경매(입찰·자동 마감)와 제작 의뢰 역경매(작가들이 더 낮은 가격을 제안) |
| 지도 매칭 | 집 주변 작품을 지도에서 탐색 (카카오맵, 거리순 목록 폴백) |
| 디지털 소유권 + QR 인증 | 결제 확정 시 소유권 인증서 자동 발급, QR 스캔으로 누구나 소유권 이력 확인 |

## 확정된 제외 사항 (사용자 확정)

- **블록체인 없음** — 디지털 소유권은 서버 DB 기반이다.
- **배송 없음** — 만나서 전달하는 직거래. 이 때문에 결제가 "만난 뒤"로 미뤄지는 독자적인 거래 흐름을 가진다(→ 도메인 설계 > 직거래 결제 흐름).
- **'정품 인증' 개념 없음** — 위작 판별 서비스가 아니다. 모든 표기는 **'소유권 인증'**으로 통일(2026-08-05 확정).

## 브랜드

- 표기는 **ART NARA** 로 통일(2026-08-02). 옛 이름(DUST-ART) 잔재는 내부 식별자까지 전부 개명 완료 — 코드베이스에 DUST 문자열이 남아 있지 않다(2026-08-06).
- 워드마크는 텍스트(ART·NARA) + 오렌지 점으로 코드에서 그린다.
